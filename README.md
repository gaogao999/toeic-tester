# EIS合格応援アプリ

**Ekamai International School (EIS) の Grade 8 受験**に向けた学習アプリです。
入試は **英語** と **算数** の 2 科目なので、アプリもその 2 つで構成しています。

| 科目 | 内容 |
| --- | --- |
| 📖 英語 | 長文読解 134 本（設問 523 問）＋ 単語 2,306 語 |
| 🔢 算数 | 問題 149 問 — 小学校の復習から中学1年まで |

どちらも難易度と分野で出題範囲を絞り込めます。

**英語のデータはすべて TOEFL Junior の教材3冊から取っています。** 単語は「教材の本文に出てくる語」
だけを収録し、レベルはその語が最初に出てくる本文の難易度をそのまま使っています。
外部の単語リストや英検の級は基準に使っていません（EIS が英検を基準にしている証拠が無いため）。
難易度は **CEFR**（A2 / B1 / B2）で示します。ETS が TOEFL Junior と CEFR の対応を公表しているためです。
ビルド不要・インストール不要で、`index.html` をブラウザで開くだけで動きます。

## 使い方

```bash
git clone https://github.com/gaogao999/toeic-tester.git
cd toeic-tester
```

そのまま `index.html` をブラウザで開いてください。ローカルサーバー経由で見たい場合は次のいずれかで起動できます。

```bash
python3 -m http.server 8000   # → http://localhost:8000
npx http-server -p 8000
```

## 機能

### ホーム
**試験日までの残り日数 → 今日の学習メニュー → カレンダー** の3つだけの構成です。
アプリを開いてすぐ「あと何日か」「今日は何をやるか」が分かるようにしてあります。
各機能へはタブから移動します。

### 画面の切り替え（スワイプ）
スマートフォンでは、**画面を左右に払う（スワイプする）とタブが隣に移動します。**

- 左へ払うと次のタブ、右へ払うと前のタブへ。端まで来たらそれ以上は動きません。
- 移動すると、選択中のタブが見えるところまでタブバーが自動で寄ります。
- **縦にスクロールしているつもりの動きでは反応しません**（縦の移動が大きい場合は無視します）。
- 文字入力欄の上と、タブバー自体の上（横スクロール用）ではスワイプは効きません。
- スワイプの直後に起きるタップは打ち消すので、**単語カードの上を払ってもカードはめくれません。**

### 今日の学習メニュー
ホーム画面の中段に、その日にやることが自動で出ます。

- **ノルマは曜日で決まっています。**

  | | 単語 | 算数 |
  | --- | --- | --- |
  | 平日 | 20 語 | 15 問 |
  | 土日 | 25 語 | 20 問 |

  **長文読解は「1 本」です。設問の数では数えません。**
  設問が 2 問しかない本文もあり、それで達成にすると 300 語読んで 2 問で終わってしまうためです。
  本文を最後まで解いて 1 本と数えます。単語・算数の数を変えるときは `js/app.js` の `DAILY_GOALS` を編集してください。
- 単語・算数・長文読解の3本立て。**解くたびにその場で消化状況が進み**、達成すると ✓ が付きます。
- 各行をタップするとその画面に移動します。何をやるか迷う時間をなくすための機能です。

### 模擬試験
形式が2つあります。**測りたいものが違うので、両方あります。**

| | 何のため | 進み方 |
| --- | --- | --- |
| **レベル判定**（既定） | いまどのくらいの実力か**を測る** | やさしい問題から始めて、出来に応じて難易度が上下する |
| **本番形式** | **時間内に解き切る**練習 | 決まった問題数を制限時間つきで通しで解く |

どちらも構成は「英語＋算数」「英語だけ」「算数だけ」から選べます。

#### レベル判定（適応型）
**簡単な問題から始めて、少しずつ難しくしながら実力を推し量ります。**

- **2問続けて正解すると難易度が1段上がり、1問間違えると1段下がります。**
  これを繰り返すと、難易度は**正答率がおよそ7割になる高さ**で行ったり来たりします。
  その**折り返し地点の平均**を「いまのレベル」とみなします（心理物理学でいう階段法です）。
- 出だしは**かならず一番やさしい段から**。いきなり難しい問題で心が折れないようにしています。
- 難易度の段は英語が4段（英検5級・4級 → 3級 → 準2級 → 2級）、算数が3段（小学校の復習 → 中1の基本 → 中1の発展）です。
  **単語も長文も4段そろっている**ので、英語は最上段まで頭打ちなく測れます。
  **算数だけを選んだときは英検の級ではなく学年の段階で表示します**（算数の出来を英検何級とは呼べないため）。
- **時間制限はありません。** 急がせると実力より低く出てしまうためです。
- **前の問題には戻れません。** 戻られると難易度の上げ下げが辻褄の合わないものになります。
- 最大 15問 / 20問 / 30問。**難易度が6回折り返した時点で、上限に届かなくても打ち切ります**（それ以上解いても精度がほぼ上がらないため）。
- 採点後に**難易度の推移が棒グラフ**で出ます。棒の高さが難易度、緑が正解・赤が不正解です。

#### 本番形式
**途中で答え合わせはせず、最後にまとめて採点します。**

- 規模は 20問15分 / 30問30分 / 40問45分 の3段階。**残り時間が1分を切ると赤くなります。**
- 時間切れになると自動で採点されます。
- 飛ばして後から戻れます。選んだ答えは保持されます。

#### 両方に共通
- 採点後は**科目別の得点**（単語/長文読解/算数）と、全問の正誤・自分の解答・正解が一覧で出ます。
- 直近5回の結果（形式・正答率・所要時間）が残ります。

### 実力診断（模擬試験のあと）
採点のあとに「**いま英検何級くらいか**」と、次にやることが出ます。経路は2つあり、
**どちらでも診断は出ます**。

| | いつ使われるか | 出るもの |
| --- | --- | --- |
| **AIによる診断** | 学習記録タブで Anthropic の APIキーを設定したとき | 到達級とその根拠、講評、得意・弱点と対策、次の一手（Claude が文章で書きます） |
| **正答率からの判定** | APIキーが未設定のとき、またはAIの呼び出しに失敗したとき | 到達級とその根拠、時間配分の指摘、苦手分野からの復習提案 |

判定の材料は**この回の点数だけではありません。** 30問の模擬試験に出る単語は数問なので、
**これまでの学習記録から級ごとの正答率を集計して**渡しています。

級を決めるルールは次の順です。

1. **レベル判定（適応型）を受けた回は、その推定レベルを優先します。**
   難易度を上下させて測った値のほうが、たまたまの出題運に左右されにくいためです。
2. そうでない回は「**解答数が5問以上あり、正答率70%以上を保てている一番上の級**」。

なお **1 の 7 割と 2 の 70% は同じ線です。**
2問上げ・1問下げの階段法が落ち着く高さがちょうど正答率7割付近なので、
どちらの経路で判定しても同じ基準で級を語れるようにしてあります。

**上限に達したときは正直に伝えます。** 一番難しい段（英検2級）まで上がりきってしまった場合、
それは用意した問題の上限に届いただけで、本当の実力はもっと上かもしれません。
画面にも AI への指示にも「これ以上は測れていない」と明記しています。

- 画面の下に**どちらの経路で出した診断か**が必ず表示されます（AIの文章と機械判定が混ざらないように）。
- AIの呼び出しに失敗しても診断は止まりません。**失敗の理由を添えて**正答率からの判定に切り替わります。

**APIキーについて。** 設定（⚙）の「AIの設定」で保存します。**入れると2つのことが使えます。**

| | キーがあるとき | 空のとき |
| --- | --- | --- |
| 模擬試験の診断 | Claude が文章で書く | 正答率から機械的に判定する |
| 単語カードの例文 | **和訳が付く** | 英文だけを表示する |

- キーは**このブラウザの中だけ**に保存され、**学習データの書き出しには含まれません**（バックアップから漏れないように、別のキーで保存しています）。
- ただし**ブラウザに保存する以上、この端末を使える人には読めます。** 共用の端末では使わないでください。
- **利用料はキーの持ち主のアカウントに請求されます。** 診断1回で数円程度です。
- 使うモデルは `claude-opus-5`。`js/ai.js` の `MODEL` で変えられます。

### 受験までのカウントダウンとカレンダー（ホーム）
- 試験日 **2027年1月7日（木）** までの残り日数を大きく表示します。
- 「あと ◯ 週間と ◯ 日」と、**未習得語数から計算した1日あたりの必要ペース**を表示します。
- カレンダーで試験日（🎯）・今日・**学習した日**（緑の点）が一目で分かります。前後の月にも移動できます。
- **試験日は固定です。** 画面からは変更できません（`js/app.js` の `EXAM_DATE` に定数として持っています）。

### 長文読解
入試で最も差がつくところなので、実際の形式に近づけています。

- 本文 **134 本**・設問 **523 問**。難易度は単語と同じ4段階で、**CEFR と英検の級に対応**させています。

  | レベル | 教材 | 本数 | 設問 |
  | --- | --- | --- | --- |
  | 1 | （書き下ろし） | 2 本 | 8 問 |
  | 2 | Basic（**A2**） | 43 本 | 174 問 |
  | 3 | Intermediate（**B1**） | 45 本 | 187 問 |
  | 4 | Advanced（**B2**） | 44 本 | 154 問 |

  **レベルが上がるほど本文を長くしています。** 語彙が難しくなるだけでなく、読む量そのものが増えるのが実際の試験だからです。
  長さの目安は **TOEFL Junior**（対象年齢11歳以上、ETS が CEFR との対応を公表）の読解セクションに合わせました。
- 題材は学校生活・お知らせ・手紙/メール・日常生活・理科・環境・伝記・文化・歴史・社会・科学・技術・環境経済・生物。
- 設問は 4 択。**主題／細部／文脈中の語義／指示語／推測**の 5 種類を混ぜています。
- 答えるとすぐに**日本語の解説**が出ます。どこが根拠かを本文の位置とともに示します。
- 本文の下に**語注**があり、開くと難しい語の意味を確認できます。
- **選択肢の並びは毎回シャッフルされます。** 正解の位置を覚えてしまうのを防ぐためです。
- 一覧では長文ごとに正解数が出て、全問正解すると ✓ が付きます。

### 算数
範囲は**小学校の復習から中学1年まで**。単元は日本の中1数学の並びに合わせています。
入試と同じように**問題文は英語**、**解説は日本語**です。答えは数字だけを入力します。

| 単元 | 問題数 | 内容 |
| --- | --- | --- |
| 四則計算 | 9 問 | 四則、計算の順序、最大公約数・最小公倍数 |
| 分数・小数 | 12 問 | 通分、約分、小数の計算、四捨五入 |
| 割合と比 | 12 問 | 百分率、割引、比例配分、縮尺 |
| 速さ・文章題 | 12 問 | 速さ・時間・距離、仕事算、単位の変換 |
| 正負の数 | 22 問 | 絶対値、加減乗除、累乗、四則の混じった計算、素因数分解 |
| 文字と式 | 16 問 | 文字式の表し方、式の値、同類項、分配法則 |
| 一次方程式 | 10 問 | 移項、かっこのある式、文章題 |
| 比例と反比例 | 10 問 | 比例定数、y=ax、y=a/x、座標 |
| 平面図形 | 19 問 | 面積・周・角度、円、おうぎ形、多角形の内角 |
| 空間図形 | 11 問 | 角柱・円柱・角錐・円錐の体積、表面積、面と辺の数 |
| データの活用 | 16 問 | 度数分布、相対度数、累積度数、階級値、代表値、確率 |

レベルは学年で分けています。**小学校の復習 21 問 / 中1の基本 76 問 / 中1の発展 52 問**。

- Enter で採点、もう一度 Enter で次の問題へ（単語クイズと同じ操作です）。
- 答えは `0.75` でも `3/4` でも正解になります。`1,000` のようなカンマ、前後の空白も吸収します。
- 単位が必要な問題は、入力欄の右に単位（cm² など）が出るので**数字だけ**を入力します。
- 採点後に日本語の解説が出ます。間違えた問題だけをもう一度解き直せます。
- 「まだ正解していない問題」「間違えた問題」に絞って出題できます。

### 単語カード
- 表に英単語・発音記号、裏に意味と例文を表示。カードをタップでめくれます。
  **例文の和訳は、APIキーがあればめくったときに作られます**（一度作ると保存され、次からは即出ます）。
- 「✓ 覚えた／まだ覚えていない」で回答すると、チェックが付き、次の復習タイミングが自動調整されます。
  チェック済みの単語にはカードに「✓ 覚えた」バッジが表示されます。
- 🔊 ボタンで発音を再生（ブラウザの音声合成機能を使用）。
- ☆ ボタンで「覚えにくい単語」に印を付け、あとでまとめて復習できます。
- PC ではスペースキーでめくる、左右矢印キーで移動できます。

### クイズ
形式は5つあります。**サクサク4択だけはタップで答え**、残りの4つは英単語をキーボードで入力します。

| 形式 | 内容 |
| --- | --- |
| ⚡ サクサク4択 | 英単語を見て、意味を4択から選ぶ（制限時間つき） |
| 意味 → 英単語 | 日本語の意味を見て英単語を入力する |
| 例文穴埋め | 例文の空所に入る語を入力する（例文のある 2,188 語が対象） |
| リスニング | 読み上げられた単語を聞き取って入力する |
| スペル練習 | 表示された単語をそのまま正確に入力する |

#### ⚡ サクサク4択
覚えはじめの時期に、**短い時間でたくさんの単語に触れる**ための形式です。

- 1問あたりの制限時間を **なし / 3秒 / 5秒 / 8秒** から選べます（初期値は5秒）。
  残り時間はバーが減っていく形で分かります。**時間切れは不正解**として記録されます。
- 答えるとその場で色が付きます（正解＝緑、選んだ誤答＝赤）。
  **正解なら約0.5秒で、間違えたら正解を読む時間を置いて約1.6秒で、自動的に次の問題へ進みます。**
- 連続正解が2問以上続くと「🔥 ◯ 連続正解」が出ます。結果画面に**最高連続数と1問あたりの平均秒数**が残ります。
- 誤答の選択肢は**同じカテゴリの単語から優先して**作るので、似た意味の中から選ぶことになります。
- まぐれ当たりがあり得るので、**この形式で正解しても「✓ 覚えた」チェックは付きません**（間隔反復には反映されます）。
- パソコンでは **1〜4 のキー**でも答えられます。

#### タイピング形式（残り4つ）
- Enter で採点、もう一度 Enter で次の問題へ進みます。
- 大文字・小文字、前後の空白、末尾の記号の違いは正解として扱います。
  穴埋めでは例文中の語形（`scheduled` など）も原形も、どちらも正解になります。
- 「ヒント」を押すごとに先頭の文字が 1 つずつ開き、文字数も表示されます。
- 「わからない」で答えを見ることができます（不正解として記録されます）。
- **正解した単語には自動で「✓ 覚えた」チェックが付きます。**（サクサク4択を除く）
- 終了後は結果一覧が出て、間違えた単語だけをもう一度出題できます。

### 出題範囲の設定
クイズ画面で以下を組み合わせて絞り込めます。**この設定は単語カードと単語一覧にも適用されます。**
設定は自動保存されます。

- **レベル**: 基礎 A2（1,012 語） / 標準 B1（566 語） / 応用 B2（728 語）
- **カテゴリ**: 30 分野。基本の名詞・基本の動詞・基本の形容詞・副詞のほか、学校生活、体・健康、
  時間・日付、仕事・お金、自然・天気、旅行・交通、食べ物・料理、動物・植物、家族・人間関係、
  気持ち・性格、スポーツ・趣味、家・建物、衣服・持ち物、数・量、社会・地理、理科、科学・技術、
  数学、つなぎ言葉、熟語・句動詞、設問の表現、面接・自己紹介、紛らわしい語 など
- **対象**: すべて / ✓ 覚えた単語だけ / まだ覚えていない単語だけ / 復習期限の単語 / 苦手な単語 / ★ を付けた単語 / 未学習の単語
- **出題数**: 5・10・20 問、または全問

### 単語一覧
- 一覧は 200 語ずつ表示し、「さらに表示」で読み進められます。
- 検索・並べ替え（収録順／アルファベット順／苦手順／習得度が低い順）に対応しています。

### 覚えた単語のチェック
- 単語一覧の各行のチェックボックスで、覚えた単語に印を付けられます。チェックした単語は取り消し線が付きます。
- 一覧上部の「表示」で、**✓ 覚えたものだけ / まだのものだけ** に絞り込めます。
  この絞り込みはホームの「対象」と連動しているため、そのまま単語カードやクイズの出題範囲にもなります。
- チェックは単語カードの「✓ 覚えた」ボタン、クイズの正解でも自動的に付きます。

### 学習記録
- 総解答数、通算正答率、連続学習日数、苦手な単語数、✓ 覚えた語数、マスター語数
- **分野別の正答率** — 単語のカテゴリ、長文の題材、算数の単元ごとに正答率を出し、
  **低い順に並べます**。80%以上は緑、60%以上は橙、それ未満は赤。
  「正負の数は90%だが比例と反比例は40%」のように、次に何をやるべきかが分かります。
- 直近 14 日間の学習量グラフ
- 習得段階（後述のボックス）ごとの単語数分布
- 学習データの書き出し・読み込み（JSON）、リセット

## 間隔反復（Leitner システム）について

単語ごとに 0〜5 の「ボックス」を持ち、正解すると 1 つ進み、不正解だと 1 つ戻ります。
ボックスに応じて次の復習日が決まるため、覚えていない単語ほど繰り返し出題されます。

| ボックス | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| 次の復習まで | すぐ | 1 日後 | 3 日後 | 7 日後 | 14 日後 | 30 日後 |

ボックス 5 に到達した単語は「マスター」として集計されます。
出題範囲の「復習期限の単語」を選ぶと、復習日を迎えた単語だけが出題されます。

## データの保存先

学習履歴はブラウザの `localStorage`（キー: `eis-app:v1`）に保存されます。
サーバーには何も送信されません。別の端末やブラウザに引き継ぐ場合は、学習記録画面の
「学習データを書き出す」で JSON を保存し、移行先で「学習データを読み込む」から復元してください。

## 単語データの出典

単語 4,918 語は、公開されている次のデータを組み合わせて作っています（熟語 204 件は手書き）。
`node tools/build-vocab.mjs` で組み立て直せます（元データは初回に取得され、
`data/raw/vocab-sources/` にキャッシュされます。`--fetch` を付けると取り直します）。

| 使ったもの | 何に使ったか | 利用条件 |
| --- | --- | --- |
| **CEFR-J Wordlist Version 1.5** | どの語を収録するか、どのレベルに置くか | 研究・商用ともに無償。出典表示が必要 |
| **ejdict-hand** | 日本語の意味 | パブリックドメイン |
| **ipa-dict** (en_US) | 発音記号 | MIT |
| **FrequencyWords** (en_50k) | 同じレベル内での優先順位 | CC BY-SA 4.0 |

> The CEFR-J Wordlist Version 1.5. Compiled by Yukio Tono, Tokyo University of Foreign Studies.
> Retrieved from http://www.cefr-j.org/download.html
> 著作権は東京外国語大学 投野由紀夫研究室に帰属します。

**レベルは英検の級で表示しますが、中身は CEFR-J です。** 英検と CEFR の対応は
英検協会が公表しているので、それに従って読み替えています。

| 表示 | CEFR | 語数 |
| --- | --- | --- |
| 英検5級・4級 | A1 | 915 語 |
| 英検3級 | A2 | 1,243 語 |
| 英検準2級 | B1 | 2,091 語 |
| 英検2級 | B2 | 873 語 |

自分で選んだのではなく、日本人学習者向けに作られた基準に従っているので、
「なぜこの語がこのレベルなのか」に根拠があります。

**級ごとの語数は英検の目安と完全には一致しません。** CEFR-J の B1 は英検準2級より
範囲が広く、B2 は英検2級より広いためです。合計は英検2級の目安（約5,100語）に合わせて
頻度の高い順に 5,122 語で打ち切っています（`--target` で変えられます）。
C1 以上は Grade 8 の受験には過剰と判断して外しました。

組み立てのときに機械的にやっていること:

- 冠詞・代名詞・be動詞など、カードにしても学習にならない品詞と語を外す。
- 辞書の語義は長いので、**品詞に合う語義を選んで**短く整えます。
  先頭を機械的に採ると `surprise` が「を驚かす」（動詞の語義）になってしまうため、
  名詞なら名詞らしい語義を探します。
- 中学生向けに不適切な語は除外します。
- 辞書が古く、第1語義が現在の中心的な意味とずれる語（`bank`→「土手」、
  `computer`→「計算機」など）は、`tools/build-vocab.mjs` の `OVERRIDES` で訂正しています。

**既知の限界:**

- **例文があるのは 702 語だけ**です（自作の 530 語＋熟語 204 件のうち重複を除く）。
  自動生成した 4,420 語は意味・発音記号・レベルは揃っていますが例文が空で、
  穴埋めクイズには出ません（他の 4 形式では出題されます）。
- 発音記号が無い語が 238 あります。ほとんどが複数語の熟語です。
- カテゴリは意味からの自動判定なので、大まかです。分類しきれなかった語は
  「基本の名詞 / 基本の動詞 / 基本の形容詞・副詞」に入ります。
- 訂正表は目視で見つけた分だけです。使っていて変な意味を見つけたら
  `OVERRIDES` に足して組み立て直してください。

### 熟語について

熟語 204 件は `tools/idioms.mjs` に手で書いています。全件に例文と和訳が付いています。
辞書データから取ろうとしましたが、ejdict の複数語見出しは固有名詞や俗語が中心で、
CEFR-J の複数語も `bus stop` のような複合名詞ばかりだったため、自動では作れませんでした。

内訳は 英検3級 72 件 / 準2級 71 件 / 2級 61 件。`look forward to` のような句動詞から、
`according to` `on the other hand` のような長文で効く表現まで入れています。

## 単語リストをまとめて取り込む

手持ちの単語リストや、Web の単語リストページからコピーしたテキストを一括で取り込めます。

1. `data/raw/` に `level1.txt`（基礎） / `level2.txt`（標準） / `level3.txt`（応用）を置く
   （ページを選択してコピー＆貼り付け、または保存した HTML をそのまま置く）
2. 次を実行する

```bash
node tools/import-words.mjs
```

`js/data.js` が更新され、ファイル名に応じてレベル1 / 2 / 3 が割り当てられます。
用意できたファイルだけでも動きます。

取り込みの挙動:

- 「`□ 音声 1 abandon [əbǽndən] 動 ～を見捨てる、放棄する`」のような行から、単語・発音記号・品詞・意味を自動で分解します。
  タブ区切り、番号付き、括弧付き品詞なども解釈できます。見出し行や説明文は無視され、
  読み取れなかった行は件数と例が表示されます。
- すでに `js/data.js` にある単語は、**例文・カテゴリ・id を保ったままレベルだけ更新**します。
  id が変わらないため、取り込み後も学習履歴はそのまま引き継がれます。
- 新しく追加された単語は例文が空、カテゴリは `未分類` になります。例文がない単語は
  穴埋めクイズの対象外となり、他の 3 形式で出題されます。例文とカテゴリは
  `js/data.js` を直接編集すれば後から追加できます。
- `data/raw/` の中身は `.gitignore` で除外されるため、取り込み元の生データはコミットされません。

## 単語を 1 語ずつ追加・編集するには

`js/data.js` の `WORD_DATA` に次の形式で追記してください。`id` は学習履歴の保存キーになるため、
既存の値は変更せず、新しい単語には未使用の番号（3001 以降）を割り当ててください。
`tools/build-vocab.mjs` は既存の id・例文・意味・カテゴリを保ったまま追記するので、
手で足した単語が上書きされることはありません。

```js
{
  id: 3001,
  word: 'negotiation',
  phonetic: '/nɪˌɡəʊʃiˈeɪʃn/',
  pos: 'n.',                       // n. / v. / adj. / adv. / prep. / phr.
  meaning: '交渉',                  // クイズの問題文になるので日本語だけにする
  note: '',                        // 混同しやすい語などの補足（省略可）
  example: 'The negotiation lasted three hours.',
  exampleJa: 'その交渉は3時間続いた。',
  level: 2,                        // 1=基礎(A1) / 2=標準(A2) / 3=応用(B1)
  category: '仕事・お金'            // 新しい名前を書けばカテゴリも自動で増えます
}
```

`note` は単語カードの裏、クイズの解説、単語一覧の詳細に「⚠」付きで表示されます。
`complement` と `compliment` のような紛らわしい語の注意書きに使います。
**問題文には出ない**ので、答えのヒントになってしまう心配はありません。

例文穴埋めクイズは、例文の中に見出し語（語尾の -s/-ed/-ing などの変化を含む）が現れる単語だけを
自動的に出題対象にします。例文に見出し語が含まれていない単語は、他の 4 形式でのみ出題されます。

## 算数の問題について

全 149 問の答えは、生成時に検算しています（問題ごとに計算式を持たせ、答えと一致するかを機械的に照合）。
四捨五入が絡む 2 問だけは手計算で確認しています。

問題を追加・修正するときは `js/math-data.js` を直接編集してください。

```js
{
  id: 'm87',                       // 単語と区別するため 'm' で始める
  question: 'Solve for x: 2x = 18',
  answer: '9',                     // 数値の文字列。単位は含めない
  unit: '',                        // 入力欄の右に出す単位（省略可）
  explanation: '両辺を 2 で割って x = 9。',
  level: 2,                        // 1=小学の復習 / 2=中1の基本 / 3=中1の発展
  category: '一次方程式'
}
```

### 収録の考え方

もともとは「長文で差がつく語」を優先して 530 語を選んでいました。ところが自作の長文 8 本を
その 530 語で読めるか測ったところ、**内容語の 75% が未収録**でした。足りなかったのは難しい語ではなく
`water` `people` `eat` `time` のような**土台の基本語**です。そこで CEFR-J を基準に基礎から
積み直し、カバー率は **25% → 87%** になりました（残りは `ate` `began` のような不規則変化と、
`microplastics` のようにその長文にしか出ない語です）。
