# EIS合格応援アプリ

**Ekamai International School (EIS) の Grade 8 受験**に向けた学習アプリです。
入試は **英語** と **算数** の 2 科目なので、アプリもその 2 つで構成しています。

| 科目 | 内容 |
| --- | --- |
| 📖 英語 | 長文読解 134 本（設問 523 問）＋ 文法 706 問 ＋ 単語 3,037 語 |
| 🔢 算数 | 問題 884 問 — Grade 3〜7（小3〜中1）の全単元 |

どちらも難易度と分野で出題範囲を絞り込めます。

> **いまは A2（基礎）を出していません。** 易しすぎて学習にならないため、英語の3科目
> （単語・長文読解・文法）とも **B1 以上だけ**を出しています。長文の入門（A1）も同じ理由で伏せています。
> 算数はそのまま Grade 3〜7 の全部を出します。
>
> | | 出る | 伏せている |
> | --- | --- | --- |
> | 単語 | 1,320 語 | 1,717 語 |
> | 長文読解 | 89 本 / 341 問 | 45 本 / 182 問 |
> | 文法 | 614 問 | 92 問 |
>
> **データは消していません。**`js/app.js` の `MIN_LEVEL` を `2` に戻せばそのまま出ますし、
> ID を変えていないので以前の学習記録もそのまま生きます。

**英語のデータはすべて TOEFL Junior の教材から取っています。** 単語の出どころは2つです。

| 出どころ | 語数 | 意味の作り方 |
| --- | --- | --- |
| 読解教材3冊の**本文に出てくる語** | 2,299 | 教材の語注 → 英和辞書の順 |
| 文法教材3冊の**設問文・本文** | 738 | 英和辞書（手直し表で補正） |

**教材の本文から取れた語だけを収録しています。**別ファイルの語彙練習リスト（xlsx）から
入っていた620語は、レベルの根拠も例文も持てなかったので取り除きました。
同義語・対義語は、教材由来の語に付くぶん（227語）だけを単語カードに表示します。
レベルは、その語が最初に出てくる本文の難易度をそのまま使っています。
外部の単語リストや英検の級は基準に使っていません（EIS が英検を基準にしている証拠が無いため）。
難易度は **CEFR**（A2 / B1 / B2）で示します。ETS が TOEFL Junior と CEFR の対応を公表しているためです。
ビルド不要・インストール不要で、`index.html` をブラウザで開くだけで動きます。

## 機能

### 画面の構成 — 下タブは3つ

| タブ | 何をする場所か |
| --- | --- |
| **セッション** | 「何分やる？」を選んで座る。**ふだん押すのはここだけ**で済むようにしてあります |
| **ぜんぶ** | 科目ごとの練習と模擬試験。セッションに任せないときだけ開きます |
| **きろく** | 単語の残り・今週解いていた時間・設問タイプ別の正答率・算数の単元マップ |

設定（⚙）は右上から開きます。**いま動いているリビジョン**（日付と短縮ハッシュ）は
設定画面のいちばん下にあります。スマートフォンで開いたときに、手元のものが最新かを
確かめるためのものです。ビルド工程が無いので実行時に git を読めません。
かわりにコミットの直前に刻みます。

```bash
node tools/stamp-version.mjs   # js/app.js の APP_VERSION を書き換える
```

### 画面の切り替え（スワイプ）
スマートフォンでは、**画面を左右に払う（スワイプする）とタブが隣に移動します。**

- 左へ払うと次のタブ、右へ払うと前のタブへ。端まで来たらそれ以上は動きません。
- 移動すると、選択中のタブが見えるところまでタブバーが自動で寄ります。
- **縦にスクロールしているつもりの動きでは反応しません**（縦の移動が大きい場合は無視します）。
- 文字入力欄の上と、タブバー自体の上（横スクロール用）ではスワイプは効きません。
- スワイプの直後に起きるタップは打ち消すので、**単語カードの上を払ってもカードはめくれません。**

### セッション —「20分だけ座る」

**献立を自分で組みません。分だけを選べば、中身はアプリが決めます。**

以前は「今日の学習」として単語20語・算数15問…と曜日ごとのノルマを出していました。
ノルマは、達成できなかった日に「今日はもう無理だ」と手を止めさせます。
**分で区切れば、途中でやめてもやったこと自体は残る**ので、連続日数が途切れません。

なお、**「20分」は自分に出す予算**であって、アプリが「20分座った」と認めるわけではありません。
記録に残るのは**実際に問題を解いていた時間**です（下の「結果」を見てください）。

#### 1日のミニマム

**その日に必ず超えたい床**です。ホームのいちばん上に進み具合が出て、
セッションは**残っているミニマムから先に**問題を出します。

| | ミニマム | 数え方 |
| --- | --- | --- |
| 単語 | **20個 正解** | 答えた数ではなく**正解した数**です。当てずっぽうで20回押しても達成になりません |
| 長文読解 | **1本** | 設問の数ではなく本数です。設問2問の本文で達成にしないためです |
| 算数 | **15問** | 解いた数です |

- **文法にミニマムはありません。**ミニマムが残っているあいだは後回しになり、
  床を踏み終えた回から出ます。1日に2回セッションをすればまず出ます。
- **達成できなくてもセッションは成立します。**以前の「今日の学習」（曜日ごとのノルマ）と違い、
  未達を責める言い方はしません。足りない数を出すだけで、翌日に持ち越しもしません。
- 単語は「正解した数」なので、**何問出せば足りるかは正答率しだい**です。
  これまでの正答率で割り増して出題しますが（最大2倍まで）、外れたぶんは次の回が拾います。
  そのため「この回で踏み終えます」ではなく「**届く見込みです**」と出します。
- ミニマムを踏んだ日は、きろくの週グラフに ✓ が付きます。
- 数を変えるときは `js/app.js` の `DAILY_MINIMUM` を編集してください。

20分のセッションではミニマム全部は入りません（ざっと28分ぶんあります）。
**2回に分けて踏む**のが想定の使い方です。

#### 何分やる？

**5分・10分・20分・40分**から選びます。中身は次のように決まります。

0. **残っているミニマムを先に詰めます。**3科目を同じ歩調で減らすよう、
   「その科目の残りを片づけるのにかかる時間」の比で配ります。
   時間が足りなければ同じ割合で縮め、足りないぶんは次の回に回します。
   ここから先（1〜3）は、**ミニマムを踏み終えたあとに余った時間**の配り方です。
1. **時間を科目に配る。**均等割りを土台に、正答率の低い科目へ寄せます。
   ただし**動かすのは最大 ±30%**まで。全部を弱点科目に寄せると、得意な科目に
   一度も触れない日ができるためです（入試では4科目とも出ます）。
2. **配った時間を問題数に直す。**1問あたりの目安は科目でまるで違います。

   | | 単語 | 長文読解 | 文法 | 算数 |
   | --- | --- | --- | --- | --- |
   | 1問あたり | 20秒 | 90秒 | 40秒 | 60秒 |

   長文の90秒は「本文を読む時間を設問数で割ってならしたもの」です。
   総問題数ではなく**時間で配る**のは、長文が多い回だけ倍かかってしまうためです。
3. **長文は本文の単位でしか出しません。**1本ぶんに満たない配分の回（5分・10分）は
   長文を外し、そのぶんを他の科目に回します。本文を読んだところで時間が終わるためです。

`js/app.js` の `SESSION_SECONDS` と `SESSION_MINUTES` で調整できます。

#### 出題の順番

**科目ごとのブロックで出ます**（単語 → 長文読解 → 文法 → 算数）。
単語と算数が交互に来ると頭の切り替えばかりで疲れるためです。
科目の切れ目には緑の帯（`単語15問おわり ・ ここから長文読解`）が出ます。

- 1問ごとにその場で正誤と日本語の解説が出ます（模擬試験と違い、最後にまとめてではありません）。
- 上に**のこり時間**と、科目ごとの進み具合の帯が出ます。帯の幅はそのまま問題数の比です。
- **セッション中は下タブが消えます。**途中で別の画面へ行かせないためです。
- **時間が来てもその場で打ち切りません。**解いている途中の問題を消すと、
  「座れた」感覚ごと取り上げることになるためです。いまの1問を終えたところで閉じます。

#### 中断と再開

**「やめる」ではなく「中断」です。**押すとそこまでが控えられ、ホームに
「きのうの途中から」のカードが出ます。押せば続きから始まります。

- 1問答えるたびに控えているので、アプリを閉じられてもそこまでは残ります。
- 控えるのは**問題そのものではなく id だけ**です。開き直すときに組み立て直します。
- データを入れ替えて問題が見つからなくなったときは、諦めて組み直します。

#### 結果

- **「9問、やった。」**が見出しです。以前は「20分、座れた。」でしたが、
  **アプリは座ったかどうかを知りません。**分かるのは画面を開いていた時間だけで、
  開いたまま置いておけば増えてしまいます。確かめられるのは答えた数なので、そちらを言います。
- 時間は**「解いていた時間」**として出します。1問ずつ、出してから答えるまでを
  足したものです（5分を超えたぶんは離席とみなして切り捨てます）。
- 連続日数と、これまでの最長までの差（`最長11日まであと4日`）。
- 科目ごとの正答率の帯。7割を下回った科目は赤くなります。
- **長文の1問あたりの秒数**を出します。1問ずつ実際に測った時間で、
  直近3回の平均と比べて「前は◯秒」と添えます。目安から逆算した数は出しません。
- **次の20分の中身**を、この回の出来を反映して先に見せます。

### 出題の重心（ぜんぶタブ）

セッションが問題を選ぶときの方針です。

| | 何が出るか |
| --- | --- |
| **いまの実力に合わせる**（既定） | レベル判定で出た段だけ |
| **一番上だけ** | 応用 B2・Grade 7 だけ |
| **苦手だけ** | 間違えたまま・まだ解いていない問題だけ（段は問わない） |

絞りすぎて在庫が空になったら、**絞りを外して出します。**
「今日は出せる問題がありません」で終わらせないためです。

### レベル判定で出た段で開く

**レベル判定を受けていると、「ぜんぶ」の各行に測った段が出ます**（`単語 応用 B2` のように）。
タップすると**その段に絞って**開くので、いま伸ばすところだけを練習できます。
まだ受けていなければ段は出ず、これまで通り保存された出題範囲で開きます。
結果は科目ごとに控えているので、英語だけで測ったあとに算数だけで測っても、
英語の段は消えません。

### 模擬試験
形式が2つあります。**測りたいものが違うので、両方あります。**

| | 何のため | 進み方 |
| --- | --- | --- |
| **レベル判定**（既定） | いまどのくらいの実力か**を測る** | やさしい問題から始めて、出来に応じて難易度が上下する |
| **本番形式** | **時間内に解き切る**練習 | 決まった問題数を制限時間つきで通しで解く |

どちらも構成は「英語＋算数」「英語だけ」「算数だけ」から選べます。

#### レベル判定（適応型）
**簡単な問題から始めて、少しずつ難しくしながら実力を推し量ります。**

- **科目ごとに別々の難易度で進みます。**単語・長文読解・文法・算数それぞれに階段が1本あり、
  結果も**科目ごとに出ます**。「単語は 応用 B2 だが長文読解は 標準 B1 より下」のように、
  どこが足を引っぱっているかが分かります。
- **2問続けて正解すると難易度が1段上がり、1問間違えると1段下がります。**
  これを繰り返すと、難易度は**正答率がおよそ7割になる高さ**で行ったり来たりします。
  その**折り返し地点の平均**を「いまのレベル」とみなします（心理物理学でいう階段法です）。
- **ただし「その段で7割取れているか」も別に見ます。**4択はまぐれでも当たるので、
  難易度が上がっただけでは到達とみなしません。階段の値と、7割取れている一番上の段の
  **低いほう**を採ります。どの段も取れていなければ「◯◯ より下」と出ます。
- 出だしは**かならず一番やさしい段から**。いきなり難しい問題で心が折れないようにしています。
- 難易度の段は英語が4段（入門 A1 → 基礎 A2 → 標準 B1 → 応用 B2）、算数が5段（Grade 3 → 4 → 5 → 6 → 7）です。
  **算数は CEFR ではなく学年（Grade 3〜7）で表示します**（算数の出来を CEFR では呼べないため）。
- **問題数は「1科目あたり」で決めます。**短め6問／標準10問／じっくり15問。
  4科目そろえた回なら 24／40／60 問です。総数で決めると科目が増えたぶん1科目が痩せて、
  どの科目も測れなくなるためです。
- 見出しに出る1つの段は、**英語3科目のうち一番低いところ**に合わせています。
  入試では3科目とも出るので、一番弱いところが足を引っぱるためです。
- **時間制限はありません。** 急がせると実力より低く出てしまうためです。
- **前の問題には戻れません。** 戻られると難易度の上げ下げが辻褄の合わないものになります。
- **全科目の難易度が6回ずつ折り返した時点で、上限に届かなくても打ち切ります**（それ以上解いても精度がほぼ上がらないため）。1科目だけ落ち着いても止めません。
- 採点後に**科目ごとの難易度の推移が棒グラフ**で出ます。棒の高さがその科目の中での難易度、緑が正解・赤が不正解です。
- **3問に満たない科目は判定しません。**「測るには問題数が足りない」と出します。

#### 本番形式
**途中で答え合わせはせず、最後にまとめて採点します。**

- 規模は 20問15分 / 30問30分 / 40問45分 の3段階。**残り時間が1分を切ると赤くなります。**
- 時間切れになると自動で採点されます。
- 飛ばして後から戻れます。選んだ答えは保持されます。

#### 両方に共通
- 採点後は**科目別の得点**（単語/長文読解/算数）と、全問の正誤・自分の解答・正解が一覧で出ます。
- 直近5回の結果（形式・正答率・所要時間）が残ります。

### 実力診断（模擬試験のあと）
採点のあとに「**いまどの段階（CEFR）か**」と、次にやることが出ます。経路は2つあり、
**どちらでも診断は出ます**。

| | いつ使われるか | 出るもの |
| --- | --- | --- |
| **AIによる診断** | 設定（⚙）で Anthropic の APIキーを設定したとき | 到達段階とその根拠、講評、得意・弱点と対策、次の一手（Claude が文章で書きます） |
| **正答率からの判定** | APIキーが未設定のとき、またはAIの呼び出しに失敗したとき | 到達段階とその根拠、時間配分の指摘、苦手分野からの復習提案 |

判定の材料は**この回の点数だけではありません。** 30問の模擬試験に出る単語は数問なので、
**これまでの学習記録から段階ごとの正答率を集計して**渡しています。

到達段階を決めるルールは次の順です。

1. **レベル判定（適応型）を受けた回は、その推定レベルを優先します。**
   難易度を上下させて測った値のほうが、たまたまの出題運に左右されにくいためです。
2. そうでない回は「**解答数が5問以上あり、正答率70%以上を保てている一番上の段階**」。

なお **1 の 7 割と 2 の 70% は同じ線です。**
2問上げ・1問下げの階段法が落ち着く高さがちょうど正答率7割付近なので、
どちらの経路で判定しても同じ基準で到達段階を語れるようにしてあります。

**上限に達したときは正直に伝えます。** 一番難しい段（応用 B2）まで上がりきってしまった場合、
それは用意した問題の上限に届いただけで、本当の実力はもっと上かもしれません。
画面にも AI への指示にも「これ以上は測れていない」と明記しています。

- 画面の下に**どちらの経路で出した診断か**が必ず表示されます（AIの文章と機械判定が混ざらないように）。
- AIの呼び出しに失敗しても診断は止まりません。**失敗の理由を添えて**正答率からの判定に切り替わります。

**APIキーについて。** 設定（⚙）の「AIの設定」で保存します。**入れると2つのことが使えます。**

| | キーがあるとき | 空のとき |
| --- | --- | --- |
| 模擬試験の診断 | Claude が文章で書く | 正答率から機械的に判定する |
| 単語カードの例文 | **和訳が付く** | 英文だけを表示する |
| 意味のふりがな | **読めない漢字に付く** | 付かない |

- キーは**このブラウザの中だけ**に保存され、**学習データの書き出しには含まれません**（バックアップから漏れないように、別のキーで保存しています）。
- ただし**ブラウザに保存する以上、この端末を使える人には読めます。** 共用の端末では使わないでください。
- **保存先はページ単位ではなくドメイン単位（localStorage の仕様）です。**
  GitHub Pages は `<ユーザー名>.github.io` の下に全リポジトリが並ぶので、
  **同じアカウントで公開している他のページからも、このキーは読み取れます。**
  他のページが外部スクリプト（CDN）を読み込んでいれば、そのスクリプトからも読めます。
  **このアプリ専用のキーを作り、Anthropic のコンソールで上限額を設定して使ってください。**
- **利用料はキーの持ち主のアカウントに請求されます。** 診断1回で数円程度です。
- 使うモデルは診断が `claude-opus-5`、和訳とふりがなが `claude-haiku-4-5`。`js/ai.js` で変えられます。
  1文を訳すだけの仕事に重いモデルは要らず、**待ち時間がそのまま体験になる**ので分けています。

### 受験までのカウントダウン（セッションタブ）
- 試験日 **2027年1月7日（木）** までの残り日数を大きく表示します。
- その下に**週マス**が並びます。**1マス＝1週**で、左端が今週、右端（緑）が入試の週です。
  日で数えると140マスになって残りの実感がかえって湧きませんが、週なら20マスで画面に収まります。
- カレンダー（試験日 🎯・今日・**学習した日**）は**きろくタブ**に畳んであります。前後の月にも移動できます。
- **試験日は固定です。** 画面からは変更できません（`js/app.js` の `EXAM_DATE` に定数として持っています）。

### 長文読解
入試で最も差がつくところなので、実際の形式に近づけています。

- 本文 **134 本**・設問 **523 問**。難易度は単語と同じ4段階で、**CEFR** で示しています。

  | レベル | 教材 | 本数 | 設問 |
  | --- | --- | --- | --- |
  | 1 | （書き下ろし） | 2 本 | 8 問 |
  | 2 | Basic（**A2**） | 43 本 | 174 問 |
  | 3 | Intermediate（**B1**） | 45 本 | 187 問 |
  | 4 | Advanced（**B2**） | 44 本 | 154 問 |

  **レベルが上がるほど本文を長くしています。** 語彙が難しくなるだけでなく、読む量そのものが増えるのが実際の試験だからです。
  長さの目安は **TOEFL Junior**（対象年齢11歳以上、ETS が CEFR との対応を公表）の読解セクションに合わせました。
- 題材は学校生活・お知らせ・手紙/メール・日常生活・理科・環境・伝記・文化・歴史・社会・科学・技術・環境経済・生物。
- 設問は 4 択。**主題／細部／文脈中の語義／指示語／推測**の 5 種類を混ぜています。
  **どの設問がどの種類かはデータに印（`type`）が付いています**（`node tools/reading-types.mjs --emit`）。
  きろくタブの「設問タイプ別」がこれを使い、**主題は取れているのに文脈中の語義だけ落ちている**
  といった差を出します。「長文 72%」という数ひとつでは、直す場所が語彙なのか読解なのか決まりません。

  | | 主題をつかむ | 細部を探す | 文脈中の語義 | 指示語 | 推測する |
  | --- | --- | --- | --- | --- | --- |
  | 設問数 | 76 | 260 | 82 | 49 | 56 |
- **一覧に出る題は日本語です。**本文の一部ではなく、選ぶための見出しだからです
  （実際の TOEFL Junior の本文に題は付いていません）。
  32 本が「題として最もふさわしいものは？」を出題するので、
  **その 32 本の見出しは主題ではなく場面を指す言い方**にしてあります。
  見出しが答えを教えてしまわないようにするためです（`node tools/reading-titles.mjs` が点検します）。
- 答えるとすぐに**日本語の解説**が出ます。どこが根拠かを本文の位置とともに示します。
- 本文の下に**語注**があり、開くと難しい語の意味を確認できます。
- **選択肢の並びは毎回シャッフルされます。** 正解の位置を覚えてしまうのを防ぐためです。
- **「🎲 ランダムで1本読む」** を押すと、まだ全問正解していない本文から1本選びます。
  何を読むか迷う時間をなくすためのものです。自分で選びたいときは「自分で選ぶ」を開きます。
- 一覧では長文ごとに正解数が出て、全問正解すると ✓ が付きます。

### 文法（Language Usage）
EIS の入試形式が **MAP Growth** に近いと分かったため、その **Language Usage** にあたる科目として足しました。
空所に入るものを選ぶ形式で、**問題文は英語・解説は日本語**です。

- 設問 **706 問**。難易度は単語・長文と同じ4段階のうち **2〜4**（A2 / B1 / B2）を使っています。

  | レベル | 教材 | 設問 | 形式 |
  | --- | --- | --- | --- |
  | 2 | Basic（**A2**） | 92 問 | 2択 |
  | 3 | Intermediate（**B1**） | 306 問 | 4択 |
  | 4 | Advanced（**B2**） | 308 問 | 4択 |

  **レベル1（A1）の問題はありません。**教材が A2 から始まっているためです。
- 単元は **16 種類**。文の要素／主語と動詞の一致／時制／受動態／助動詞／仮定法／不定詞／動名詞／分詞／
  名詞と冠詞／代名詞と数量詞／形容詞と副詞／比較／前置詞／名詞節、および複数単元をまたぐ「総合」。
- **全問に日本語の解説が付いています。**「なぜそれが正解か」を1文で書いています。
- **選択肢の並びは毎回シャッフルされます。**
- 模擬試験にも混ざります。英語の出題のうちおよそ3分の1が文法です
  （本番では Reading と Language Usage が別のセクションであるため）。

#### 正解の出どころについて

**B1・B2 の正解は、教材の解答欄からは復元できませんでした。**
解答欄が多段組みの表で、スキャンから読み取ると `1(0)` `IDI` `2NC)` `(SAD)` のように潰れ、
番号も順序も崩れていたためです。選択肢そのものは機械で拾えるので、
**正解は1問ずつ文法的に判定して書いています。**判定の根拠はそのまま解説として残してあるので、
疑わしいものは根拠を読んで直せます。A2 の解説も教材には無く、こちらで書いたものです。

### 算数
範囲は **Grade 3 から Grade 7 まで**（小3〜中1に相当）。受けるのは EIS の Grade 8 入試なので、
日本の学年ではなく**インター校の学年**で区切っています（日本の中1にない確率なども Grade 7 に入れています）。
入試と同じように**問題文は英語**、**解説は日本語**です。答えは数字だけを入力します。

英語は**アメリカ式のつづりで統一**しています（meters / liters / color / candy）。
**受けるのがアメリカ式の学校だからです。**また、英語圏の教室では通じても
日本語話者の子が読み違える言い回し（`4 lots of 0.1` など）は使いません。
**算数でつまずいてほしいのであって、英語でつまずかせたくない**ためです。

**日本語で書くのは解説だけです。**問題文・答えの単位・図のラベルはすべて英語です
（`node tools/audit-math.mjs` がこの3か所を見張ります）。

**単元は学年をまたぎます。**「分数」は G3（同じ分母）→ G4 → G5（通分）→ G6（かけ算・わり算）と
4学年に伸びています。単元で絞れば「分数だけ通しでやる」、学年で絞れば「Grade 5 相当を一巡」ができます。

**Grade 3 はつまずいたときに戻ってくる場所**として入れました。あまりのあるわり算、
分数のはじまり、ぼうグラフの読み取りまで含みます。

- **図形の問題には図が付きます。** 入試は図を読ませるので、文章だけにしていません。
  問われている角や辺は**オレンジの `?`**で示します。長さは必ず数字でも書いてあるので、
  図の見た目の比だけで解く必要はありません（細長い図形は見やすさのために少し詰めて描いています）。
- **ぼうグラフの問題は、数を問題文に書きません。**グラフの目盛りから読み取ります。
- **解答は4択です。**本番（MAP Growth）が4択なので合わせています。
  「自由入力」にも切り替えられます（そちらのほうが難しいので、力試しに）。
  **模擬試験は設定に関係なく必ず4択**です。
- **選択肢は「やりがちな間違い」で作っています。**でたらめな数を並べると、
  考えるまでもなく消せてしまい練習になりません。

  | 問題 | 正解 | 入れてある誤答 |
  | --- | --- | --- |
  | `35 + 6 × 7` | 77 | **287**（左から順に計算した） |
  | 三角形の面積（底辺10・高さ6） | 30 | **60**（÷2 を忘れた） |
  | `(−4)²` | 16 | **−16**（−4² と取り違えた） |
  | 2 km は何 m | 2000 | **200**（桁を1つ間違えた） |
- 自由入力のときは Enter で採点、もう一度 Enter で次の問題へ。
- 答えは `0.75` でも `3/4` でも正解になります。`1,000` のようなカンマ、前後の空白も吸収します。
- 比を答える問題（`3:4`）は空白の入れ方を問いません。
- 単位が必要な問題は、入力欄の右に単位（cm² など）が出るので**数字だけ**を入力します。
- 採点後に日本語の解説が出ます。間違えた問題だけをもう一度解き直せます。
- 「まだ正解していない問題」「間違えた問題」に絞って出題できます。

### 算数の単元マップ（記録タブ）
**どの単元のどの学年に穴があるか**を、25単元 × 5学年のマス目で見せます。

模擬試験が返すのは「Grade 5 相当」という数ひとつで、どの単元が弱いかは分かりませんでした。
マップだと「計算は G6 まで進んでいるが図形は G4 で止まっている」が一目で分かります。

- 色は**正解を重ねるほど濃く**なります。4段階で、凡例の4つとそのまま対応します。
  まだ（白）→ やった → 覚えてきた → 仕上がり（濃い緑）
- **赤い点**が付いたマスは、間違えたまま戻っている問題があるところです。
- 斜線のマスは、その学年にその単元の問題が無いところです。
- **マスを押すと、その単元・その学年に絞って出題します。**単元名を押すと全学年です。
  穴が見えても埋めに行けないと意味がないので、必ず1タップで解き始められるようにしています。
- マップの下に「まだ手を付けていない中でいちばんやさしい単元」が出ます。
  何からやるか迷ったらここを押してください。

単元は**習う順**に並んでいます（`tools/math-relevel.mjs` の `CATEGORY_ORDER`）。
上から下へ読むとそのまま学年が上がります。

### 学習の設定（⚙）
- **単語を自動で読み上げる** … カードをめくったとき、4択が出たときに発音します。
- **意味にふりがなを付ける** … `漆喰` `胞子` のような読めない漢字に読みを振ります。
  **小学校で習う漢字には付けません**（読めるものに付くと逆に読みにくいため）。APIキーが必要です。

### 単語カード
- 表に英単語・発音記号、裏に意味と例文を表示。カードをタップでめくれます。
  **例文の和訳は、APIキーがあればめくったときに作られます**（一度作ると保存され、次からは即出ます）。
- 「✓ 覚えた／まだ覚えていない」で回答すると、チェックが付き、次の復習タイミングが自動調整されます。
  チェック済みの単語にはカードに「✓ 覚えた」バッジが表示されます。
- 🔊 ボタンで発音を再生（ブラウザの音声合成機能を使用）。
- ☆ ボタンで「覚えにくい単語」に印を付け、あとでまとめて復習できます。
- **同義語・対義語がある語には、意味の下に出ます**（555 語）。混同しやすい語への「⚠」注意とは見た目を分けています。
- PC ではスペースキーでめくる、左右矢印キーで移動できます。

### クイズ
形式は2つです。**サクサク4択はタップで答え**、もう1つは英単語をキーボードで入力します。

| 形式 | 内容 |
| --- | --- |
| ⚡ サクサク4択 | 英単語を見て、意味を4択から選ぶ（制限時間つき） |
| 意味 → 英単語 | 日本語の意味を見て英単語を入力する |

#### ⚡ サクサク4択
覚えはじめの時期に、**短い時間でたくさんの単語に触れる**ための形式です。

- 1問あたりの制限時間を **なし / 3秒 / 5秒 / 8秒** から選べます（初期値は5秒）。
  残り時間はバーが減っていく形で分かります。**時間切れは不正解**として記録されます。
- 答えるとその場で色が付きます（正解＝緑、選んだ誤答＝赤）。
  **正解なら約0.5秒で、間違えたら正解を読む時間を置いて約1.6秒で、自動的に次の問題へ進みます。**
- 連続正解が2問以上続くと「🔥 ◯ 連続正解」が出ます。結果画面に**最高連続数と1問あたりの平均秒数**が残ります。
- 誤答の選択肢は**同じカテゴリの単語から優先して**作るので、似た意味の中から選ぶことになります。
- まぐれ当たりがあり得るので、**この形式で正解しても「✓ 覚えた」チェックは付きません**（間隔反復には反映されます）。
- パソコンでは **1〜4 のキー**でも答えられます。

#### タイピング形式（残り4つ）
- Enter で採点、もう一度 Enter で次の問題へ進みます。
- 大文字・小文字、前後の空白、末尾の記号の違いは正解として扱います。
  穴埋めでは例文中の語形（`scheduled` など）も原形も、どちらも正解になります。
- 「ヒント」を押すごとに先頭の文字が 1 つずつ開き、文字数も表示されます。
- 「わからない」で答えを見ることができます（不正解として記録されます）。
- **正解した単語には自動で「✓ 覚えた」チェックが付きます。**（サクサク4択を除く）
- 終了後は結果一覧が出て、間違えた単語だけをもう一度出題できます。

- 単語一覧の各行のチェックボックスで、覚えた単語に印を付けられます。チェックした単語は取り消し線が付きます。

### 学習記録（きろくタブ）
- **単語の残り** — 1本の帯を3つに割ります（覚えた／あやしい／のこり）。
  習得段階は5つありますが、ここは「あと何語あるか」を掴むための帯なので3つに寄せています。
  下に**直近7日のペースから見た到達日**を出します（`1日18語のペースで、試験の18日前に一周おわります`）。
- **今週、解いていた時間** — 日ごとの棒グラフ。**問題数ではなく分**です
  （1問あたりの時間が科目でまるで違うので、20問でも5分の日と20分の日ができます）。
  ただし**画面を開いていた時間ではなく、1問ずつ答えるのにかかった時間の合計**です。
- **設問タイプ別** — 長文の設問を5種類に分けた正答率。7割を切っているタイプがあれば、
  **そのタイプだけ10問**を出すボタンが付きます。
- 総解答数、通算正答率、連続学習日数、苦手な単語数、✓ 覚えた語数、マスター語数
- **伸ばせる分野** — **正答率が7割を下回る分野だけ**を出します。7割は模擬試験の
  レベル判定が落ち着く高さ・AI診断の合格ラインと同じ線です。全部できているときは
  「7割を下回る分野はありません」と出ます（低い順に3つ並べると、全部 100% の人にも
  「伸ばせる分野: 100%」と出てしまっていました）。
- **分野別の正答率** — 単語のカテゴリ、長文の題材、算数の単元ごとに正答率を出し、
  **低い順に並べます**。80%以上は緑、60%以上は橙、それ未満は赤。
  「正負の数は90%だが比例と反比例は40%」のように、次に何をやるべきかが分かります。
- 直近 14 日間の学習量グラフ
- 習得段階（後述のボックス）ごとの単語数分布
- 学習データの書き出し・読み込み（JSON）、リセット

## 間隔反復（Leitner システム）について

単語ごとに 0〜5 の「ボックス」を持ち、正解すると 1 つ進み、不正解だと 1 つ戻ります。
ボックスに応じて次の復習日が決まるため、覚えていない単語ほど繰り返し出題されます。

| ボックス | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| 次の復習まで | すぐ | 1 日後 | 3 日後 | 7 日後 | 14 日後 | 30 日後 |

ボックス 5 に到達した単語は「マスター」として集計されます。
出題範囲の「復習期限の単語」を選ぶと、復習日を迎えた単語だけが出題されます。

## データの保存先

学習履歴はブラウザの `localStorage`（キー: `eis-app:v1`）に保存されます。
サーバーには何も送信されません。別の端末やブラウザに引き継ぐ場合は、学習記録画面の
「学習データを書き出す」で JSON を保存し、移行先で「学習データを読み込む」から復元してください。

## 単語データの出典

**単語はすべて TOEFL Junior の教材から取っています。** 収録の根拠は「その語が教材に出ている」
という事実だけで、外部の単語リストや英検の級は基準に使っていません。

| 出どころ | 語数 | 意味の作り方 |
| --- | --- | --- |
| 読解教材3冊の**本文に出てくる語** | 2,299 | 教材の語注 → 英和辞書 |
| 文法教材3冊の**設問文と選択肢・本文の英文** | 738 | 英和辞書（手直し表で補正） |

**語彙練習ワークブック（別ファイルの xlsx）から入っていた620語は、すべて取り除きました。**
取り込みツールが「本文に**無い**語だけ」をリストから足す作りだったので、
620語は定義上「教材の本文に出てこない語」の集まりでした。

| | 語数 | 取り除いた理由 | 道具 |
| --- | --- | --- | --- |
| 教材の本文に一度も出てこない | 453 | レベルの根拠が無い。例文も付かない | `node tools/prune-vocab.mjs` |
| 教材には出るが、入り口がリスト | 167 | **カードが教材から作られていない** | `node tools/prune-list-vocab.mjs` |

後者を残さなかったのは、**語が教材にあることと、そのカードが教材から作られたことは別**だからです。
リスト由来のカードは本文を持たないので例文が付かず（167語すべて例文なし）、
同義語・対義語もリスト側の情報で教材には出てきません。

**そのうえで、教材に出る語は教材から入れ直しました。**
`build-vocab-from-grammar.mjs` が文法教材から **96 語**を拾い直し、うち **70 語**には
教材の例文が付きました（`blame` `progress` `accept` `knowledge` `benefit` `professor` など）。
入り口が変われば出どころが教材になるので、方針と辻褄が合います。
機械が引く語義は `grammar-vocab-overrides.mjs` で手直ししています
（`relate → 物語る`、`cross → 十字架`、`court → 中庭`、`feature → 容ぼう` のように、
辞書は古い語義・専門語義を先頭に置くためです）。

一連の入れ替えで、例文のある語は 87.7% → **92.0%**、レベルの根拠が無い語は **0** になりました。

文法教材からは、まず設問文と選択肢を使いました。**教材が誤答としてわざわざ並べた語**
（`stationed` / `illogical` / `captivating`）は「この語を知っているか」を試している語なので、
覚える価値がいちばん高いためです。
そのうえで教材の本文からも拾い、`wallet` `haircut` `umbrella` `garlic` のような
日常語を足しました。本文は OCR なので、**完全な英文だけ**を通し、さらに
**その文に含まれる語がすべて辞書に当たること**を条件にしています。1語でも壊れていれば文ごと捨てるので、
`infor` / `mation` のような分断がすり抜けません。拾った文はそのまま例文になります。

ただし **B1・B2 の長文は紙面で選択肢の枠に割られている**ため、この条件ではほとんど拾えません
（`A marsupial is a mammal that carries its babies in a small` のように句点で終わらない）。
そこで地の文からも拾いますが、文として復元はしないので**例文は付けません**。
つなぎ直すと段をまたいだ無関係な2文がくっついた例文になるためです。
こちらは OCR が壊した語が本物の英単語に化ける危険に備えて、**2回以上出てくる語だけ**を採っています。

3冊に出てくる見出し語は 2,675 語で、**その57%（1,521語）は読解教材からの2,919語ですでに覆えていました。**
新出は 1,154 語、うち 666 語を収録しています。残りは既存語の活用形（124）・文法用語や奥付（69）・
表や見出しの中にしか出ない語（223）などです。

補助として次の公開データを使っています。

| データ | 使いみち | ライセンス |
| --- | --- | --- |
| **EJDict** | 教材が意味を与えていない語の日本語 | パブリックドメイン |
| **ipa-dict** (en_US) | 発音記号 | MIT |

### レベルの決め方

**その語が最初に出てくる本文のレベル**をその語のレベルにしています。
教材そのものが Basic(A2) / Intermediate(B1) / Advanced(B2) と難易度順に分かれているので、
**外部の物差し（CEFR-J など）は持ち込みません。**

付け直すには `node tools/relevel-vocab.mjs`（`--emit` で書き込み）。
読解教材と文法教材の**本編**をすべて見て、いちばん易しい冊子に出てきたレベルを採ります。
**巻頭と巻末は数えません。**巻頭は「TOEFL Junior とはどんな試験か」を大人向けに説明した
文章で、その冊子のレベルで書かれた英文ではないためです。

**何を「その冊子のレベルの英文」とみなすかは、教材を1冊ずつ確かめてあります。**
冊子の前付（試験の説明）・後付（解答）・Directions・版面の柱・設問の定型文は数えません。
Directions は3冊とも同じ文なので、レベルの手がかりになりません。

いまの分布は **A2 1,746 / B1 670 / B2 692**。**レベルの決まらない語はもうありません。**


### 出典ごとの扱い

**その語が最初に出てくる本文の難易度**をそのまま使っています。教材の3分冊が
そのまま難易度順なので、外から物差しを持ち込む必要がありません。

| 表示 | CEFR | 教材 | 語数 |
| --- | --- | --- | --- |
| 基礎 A2 | A2 | Basic | 1,717 語 |
| 標準 B1 | B1 | Intermediate | 647 語 |
| 応用 B2 | B2 | Advanced | 673 語 |

**英検の級は使っていません。** EIS が英検を基準にしている証拠が無いためです。
CEFR を使うのは、ETS が TOEFL Junior と CEFR の対応を公表しているからです。

### 意味の作り方と、その落とし穴

意味は **手直し表 → 資料の Key Word → 教材の語注 → 英和辞書** の順に採ります。
辞書から自動で採ると壊れることが分かっているので、`tools/audit-vocab.mjs` で毎回点検します。

実際に起きた壊れ方と対処:

| 壊れ方 | 例 | 対処 |
| --- | --- | --- |
| 固有名詞との衝突 | `tell→テル` `job→ヨブ` `man→マン島` | カタカナだけの意味を洗い出して点検 |
| 古い・場違いな語義 | `school→教習所` `cell→独房` `coach→大型四輪馬車` | 辞書が『』で示す主要語義を優先 |
| 否定の抜け | `hardly→ほとんど`（正しくは「ほとんど〜ない」） | 否定を含む語を手直し表に登録 |
| 資料の読み違い | `herbivore→莫大な` | 語彙リストの意味欄は Key Word のぶんしか無いと理解して扱う |
| 答えが漏れる | `said→sayの過去` | 意味にラテン文字が残るものを弾く |

点検は次で走ります。

```bash
node tools/audit-vocab.mjs        # 要約
node tools/audit-vocab.mjs --all  # 該当する語をすべて表示
```

## 算数の問題について

**884 問。** うち m1〜m149 は手作り、m150 以降は `tools/` のスクリプトが作っています。

### 直しかた・増やしかた

`js/math-data.js` を**直接編集しないでください。**書き出しなおすと消えます。

| したいこと | さわるファイル |
| --- | --- |
| 新しい単元を足す | `tools/math-g3.mjs` 〜 `math-g7.mjs` に関数を足し、`build()` に並べる |
| 既存の手作り問題を直す | `tools/math-relevel.mjs` の `FIXES` |
| 学年・分野を付け替える | `tools/math-relevel.mjs` の `RELEVEL` |

直したら **必ずこの順で**:

```
node tools/emit-math.mjs     # js/math-data.js を書き出す
node tools/audit-math.mjs    # 点検。エラー0件になるまで直す
```

乱数は固定のたねから振っているので、**何度作り直しても同じ問題・同じ ID**になります。
学習記録は ID で保存されているので、ここが崩れると記録がずれます。

### 図

図形の問題 173 問のうち **171 問に図**が付きます（残り2問は理由があって付けていません）。
ぼうグラフの問題 14 問にも図が付きます（合計 185 問）。

データが持つのは形の指定だけで、SVG に組み立てるのは `js/math-figure.js` です。

```js
{ id: 'm104', question: '…', figure: { kind: 'rect', w: 8, h: 5, unit: 'cm' } }
```

描ける形は 20 種類 — `rect` `triangle` `isoTriangle` `parallelogram` `trapezoid` `rhombus`
`straightLine` `triangleAngles` `parallelLines` `polygon` `circle` `sector` `points` `bars`
`box` `cube` `cylinder` `prism` `pyramid` `cone`。

色は CSS 変数（`css/style.css` の `.math-figure .f-*`）から取るので、
**ダークテーマでもそのまま読めます**。SVG 側に色は書きません。

図を足したら必ず目で見て確かめてください。点検は「図形の分野なのに図が無い」
「描けない形を指定している」までは見ますが、**線が重なっていないかまでは見ません。**

### 点検が見ていること

`tools/audit-math.mjs` は、**問題文を読み直して答えを計算しなおします**。
ジェネレータが出した答えをそのまま信じません。884 問中 618 問（70%）を自動で検算し、
残りは自動では読み直せない形（文章題など）です。ほかに次を見ています。

- 答えが空、解説が空、解説に日本語がない
- 問題文の重複、ID の重複、レベルの不正
- 小数が4桁以上（何桁書けば正解か分からない問題を作らないため）
- `undefined` や `NaN` が文字列に混じっていないか
- 読み違えられる英語の言い回し（`lots of` など）が混じっていないか
- つづりが米式でそろっているか（meters / liters / color / candy）
- 図形の分野なのに図が無い／`MathFigure` が描けない形を指定している

## PDF を文字にする（教材の取り込み）

`tools/pdf-to-text.py`。**スキャン画像の PDF と、文字が入っている PDF はやることが全く違う**ので、
まず判別してから進みます。

```bash
pip install pymupdf pillow
apt-get install tesseract-ocr tesseract-ocr-jpn   # OCR を使うときだけ

python3 tools/pdf-to-text.py 教材.pdf --check      # ← まずこれ
```

判別の結果で分かれます。

| PDF の種類 | やること | 精度 | 速さ |
| --- | --- | --- | --- |
| 文字が入っている | 取り出すだけ | 誤字ゼロ | 一瞬 |
| スキャン画像 | OCR が要る | 誤字が出る | 遅い |

```bash
python3 tools/pdf-to-text.py 教材.pdf                  # 自動判別して書き出す
python3 tools/pdf-to-text.py 教材.pdf --mode images --dpi 150 --format jpg
python3 tools/pdf-to-text.py 教材.pdf --mode ocr --lang eng+jpn --pages 1-20
```

出力は `out/<PDFの名前>/` に**ページごと**（`p0001.txt`）と、まとめ（`all.txt`）。
1ファイルにまとめないのは、**取り込んだあとに誤字を見つけたとき元のページに戻れる**ようにするためです。

### OCR の結果は必ず目で見ること

きれいなスキャンでこの精度でした（実際の教材はもっと落ちます）。

| | 一致率 |
| --- | --- |
| 英語 | 100% |
| 日本語 | 97.2% |

日本語で外した1文字が **「何千キロ」→「何干キロ」** でした。**数字が壊れます。**
算数の問題や設問番号でこれが起きると、気づかないまま間違ったデータが入ります。

精度が要るなら OCR に頼らず、`--mode images` でページを画像にして
**Claude に読ませる**ほうが確実です（`js/reading-data.js` の r23〜r134 はこの方法で作りました）。

| | 語数 | カバー率 |
| --- | --- | --- |

### 例文の和訳とふりがな

例文の和訳（2,180件）と、意味のふりがなは**先に用意していません**。
カードをめくったときに AI がその1件だけ作り、結果を貯めます。実際に見る語は限られるので、
全部を用意するより無駄がありません。APIキーが無いときは、英文だけ・ふりがな無しで出ます。
