# 英単語プリント

Ekamai International School（バンコク）Grade 8 入試にむけて、
**英単語を覚えるための用紙を印刷する**だけのアプリです。

- 公開先 https://gaogao999.github.io/toeic-tester/
- ブラウザで開いて、範囲と用紙を選んで、印刷するだけ。
- **アカウントも通信も要りません。**`index.html` をそのまま開いても動きます。

> **このリポジトリは public です。**公開されたページは URL を知っていれば誰でも開けます。
> 公開されるのはアプリと単語データだけです。

---

## 使い方

1. 上のリンクを開く（スマホよりパソコンのほうが紙を確かめやすい）
2. 左で **用紙・レベル・分野・範囲** を選ぶ
3. 右に出ている紙を確かめて、**印刷する** を押す

**右に出ているものが、そのまま刷られます。**プレビュー用に別の組み方はしていないので、
画面で見た通りの紙が出ます。「全3枚」と出ていれば A4 で3ページです。

### 毎日の使い方

範囲を **「1語目から 40語」** にして刷り、終わったら **「次の分 →」** を押して
41語目から刷る。これを繰り返して端から潰していく想定です。

## 4種類の用紙

| 用紙 | 中身 | 1枚 |
| --- | --- | --- |
| **おぼえる用（一覧）** | 単語・発音記号・品詞・意味と、チェック欄3つ | 23語 |
| **テスト　意味 → 英語** | 日本語を見て英単語を書く | 22語 |
| **テスト　英語 → 意味** | 英単語を見て意味を書く | 22語 |
| **書いて覚える** | 薄い字をなぞってから、同じ行に自分で書く | 18語 |

- **解答は別の紙**で、テストの最後に付きます。折って隠せるようにするためです。
  要らなければ「解答を最後に付ける」のチェックを外します。
- **例文**を入れられるのは一覧だけです（単語の下にぶら下がります）。
  例文があるのは 3,037語中 2,795語で、無い語はそのまま出ます。
- **発音記号**はどの用紙でも外せます。
- 紙の上では**色を使いません。**家庭用プリンタで刷るので、黒一色で読めることを優先しています。

### 範囲の選び方

| | |
| --- | --- |
| レベル | すべて / 基礎 A2 / 標準 B1 / 応用 B2 |
| 分野 | すべて / 社会・地理 / 学校生活 / 日常・生活 / 理科 / 自然・天気 / 動物・植物 / 科学・技術 / 文法教材の語 |
| 並び | 収録順 / アルファベット順 / ランダム |
| 範囲 | ◯語目から ◯語（20 / 40 / 60 / 100 / 200） |

「◯語目」は**絞り込んで並べ替えたあとの位置**です。
たとえば「標準 B1・理科」に絞れば、その中の1語目から数えます。

ランダムのときは **「組み直す」** で引き直せます。押すまで並びは変わりません
（1枚目を刷ってから2枚目を刷るあいだに中身が変わらないようにするため）。

## 単語データ

**3,037語。**出どころは **TOEFL Junior 教材3冊の本文に実際に出てくる語**だけで、
「その語が教材に出ている」という事実以外の根拠は使っていません。
レベルは、その語が最初に出てくる本文のレベルです。

| | 語数 | |
| --- | --- | --- |
| 基礎 A2 | 1,717 | TOEFL Junior Basic |
| 標準 B1 | 647 | TOEFL Junior Intermediate |
| 応用 B2 | 673 | TOEFL Junior Advanced |

つづりは**米式**にそろえています（meters / liters / color / theater）。
受けるのがアメリカ式の学校だからです。

## 作るときのこと

ビルド工程はありません。`index.html` をブラウザで開けば動きます。

```
index.html
  └ js/data.js   単語 3,037語
  └ js/app.js    紙を組む
  └ css/style.css
```

```bash
node tools/audit-print.mjs   # 刷り上がりの点検（Playwright が要る）
node tools/audit-vocab.mjs   # 単語データの点検
node tools/stamp-version.mjs # コミット直前にリビジョンを刻む
```

`audit-print.mjs` は、ヘッドレス Chromium で実際に A4 の PDF を作り、
**画面の枚数と刷り上がりのページ数が合っているか**を見ます。
このアプリの中身は紙なので、画面が正しく見えても刷ると崩れていることがあります。

コードを書くときの決まりは **CLAUDE.md** にあります。

2026-11 に**用紙を刷るだけ**に作り替えました。消したものは git に残っています。

```bash
git show 10400a2 --stat                 # 何があったか
git checkout 10400a2 -- js/math-data.js # 1つだけ戻す
```

**ブラウザに入っている古い学習記録は消していません。**
保存キー（`eis-app:v1`）には触れていないので、アプリを戻せばそのまま読み出せます。
