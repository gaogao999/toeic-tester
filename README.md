# 花の英単語

花さんの英検2級〜準1級の単語帳。**紙で覚えて、アプリは記録と進捗。**
**少なく・短く・休んでも平気**に作ってある。1日15分ほど。

1. 「今日の10語を作る」→ 印刷する（大人が立ち会う）
2. 紙で覚える（5分）→ テスト（5分）
3. **テストのあとすぐ**、大人が解答を読み上げ、**本人が**「答え合わせ」で紙と同じ番号の**まちがえた語だけ**押して記録する
4. 一緒に発音を聞いて終わり。決めた数より増やさない

覚えた語は日をあけてもう一度出てくる（間隔反復）。進み具合は「記録」で見られる。
語を押すと発音が出る。

## 続けるための決めごと

家族で、子どもの学習習慣・親の関わり方・操作の手間の3つの立場から話し合って決めた。

| | |
| --- | --- |
| **はじめは10語** | 2週間で10日やったら、20語にするかを一度だけ聞く。勝手には増やさない |
| **少なめの日** | 「今日は少なめ（5語）」。休み明けや疲れた日に、やめるより5語 |
| **休み明けは復習だけ** | 期限のきた復習が1日分より多い日は、新しい語を出さずに復習だけ10語。たまった分を一度に出さない |
| **連続日数は出さない** | 1日休むと0に戻って再開しにくくなる。代わりに「今月やった日数」と「覚えた語」 |
| **点数は出さない** | 正解の数・日ごとの比べは画面に出さない。✕ は「また近いうちに出る」だけの意味 |
| **✕ を押すのは本人** | 大人は場を整える人で、採点しない。答え合わせ画面に「立ち会うかたへ」の手順がある |
| **前の日の紙** | 残っていたら「この紙を記録する」を先に出す。押しかけの ✕ は閉じても消えない |
| **きょうだいの記録は混ぜない** | このアプリは花さん専用。ほかの子は別の端末かブラウザで |

ビルドは要らない。`index.html` をブラウザで開けば動く（`file://` でも動く）。

- **ワークシートの語**は、花さんの長文ワークシート（g7lit-hana-worksheet）で出てきた語。
  文章の中で出会った語なので、設定の「出す範囲」にかかわらず**先に出す**。
- 品詞は持たない。元データの品詞が当てにならない（produce が「名詞」など）。

## 今日の語の選び方

1. 復習の期限がきた語を、期限のふるい順に**最大6割**
2. のこりを新しい語。ワークシートの語 → 2級 → 準1級の順
3. 新しい語が尽きたら、期限のきた語で埋める
4. **ただし期限のきた復習が1日分より多い日は、復習だけ10語**（期限のふるい順）

並びは作るときに1回だけ混ぜて保存する。**どの紙も、答え合わせの画面も同じ番号。**

| 結果 | 次に出る日 |
| --- | --- |
| 正解 | 1日 → 1日 → 3日 → 7日 → 14日 → 30日 → 60日後 |
| まちがい | 翌日（はじめからやり直し） |

**3回続けて正解した語を「覚えた」**と数える。

## 紙

| 用紙 | 1枚 | |
| --- | --- | --- |
| おぼえる（一覧） | 21語 | 単語・意味・チェック欄3つ |
| テスト　意味 → 英語 | 22語 | |
| テスト　英語 → 意味 | 22語 | |
| 書いて覚える | 17語 | なぞり書きつき |
| 解答 | 25語 | 最後に付ける（折って隠せる） |

- 紙の上の意味は、言い換えの並びを**頭から16字まで**に切る（画面には全部出す）
- 黒一色。家庭用プリンタで刷る前提
- 「記録」の「これまでのプリント」から、前の日の紙をもう一度刷れる

## 記録の保存

ブラウザの localStorage（`hana-eiken:v1`）。**ほかの端末やブラウザには移らない。**
「設定」→「書き出す」で JSON に保存できる。読み込みもできる。

- 1日1回、その日はじめて書き込む前の状態を自動でとっておく（「1日前に戻す」）
- 読めないデータが出てきたら捨てずに退避する

node tools/import-eigo-pet.mjs <えいごペットの words.js>   # js/data.js を作り直す
node tools/import-worksheet.mjs <used_words_hana.json>    # js/worksheet.js を作り直す
