# 単語リストの置き場所

このフォルダに、取り込みたい単語リストをテキストとして置いてください。

| ファイル名 | 割り当てられるレベル |
| --- | --- |
| `level1.txt` | レベル1（基礎） |
| `level2.txt` | レベル2（標準） |
| `level3.txt` | レベル3（応用） |

置いたら、リポジトリのルートで次を実行します。

```bash
node tools/import-words.mjs
```

`js/data.js` が更新され、アプリに反映されます。3 つのうち用意できたファイルだけでも動きます。

## 中身の作り方

単語リストのページをブラウザで開き、表の部分を選択してコピーし、テキストファイルに貼り付けるだけです。
ページを「名前を付けて保存」した HTML をそのまま置いても構いません（タグは自動で除去されます）。

次のような書式はすべて自動で解釈されます。見出し行や説明文など、単語として読めない行は無視されます。

```
□ 音声 1 abandon [əbǽndən] 動 ～を見捨てる、放棄する
2. ability	名	能力
accomplish	～を達成する
take advantage of  ～を利用する
```

取り込めなかった行は実行時に件数と例が表示されるので、必要なら手で直してください。

## 注意

- このフォルダの `.txt` / `.html` は `.gitignore` で除外され、リポジトリにはコミットされません。
  取り込み元の生データを公開せずに済むようにしています。
- 他サイトの単語リストを取り込む場合は、公開範囲や出典の扱いに注意してください。
